# Owner Access Fix

Private admin links now open the owner area reliably:

- https://www.humanlyreview.com/?owner=1
- https://www.humanlyreview.com/?admin=1
- https://www.humanlyreview.com/#owner
- https://www.humanlyreview.com/#admin

If a browser blocks the automatic modal, a floating "Open Private Owner Area" button appears only on the private owner URL.

Upload to GitHub:
- index.html
- README.md
- .nojekyll

No Apps Script deploy is required if you only replace index.html.
