# Live Chat + Telegram Update

This version adds:
- Floating Live Chat button on the website.
- Instant automated replies for common questions.
- Chat messages are saved to Google Sheets.
- Chat messages are sent to your Telegram bot.
- Automated reply is also included in Telegram notification.
- Safe message length limit.

Important:
This is not a full two-way Telegram operator chat. It is a free automated website chat + Telegram notification system.
To manually reply, use the customer's provided email or later add a more advanced Telegram webhook.
